# SHL English Practice

A web app to help students practise for SHL-style English assessments (spoken SVAR-style tasks and
written English) before placement exams. It is built on the MEAN stack (MongoDB, Express, Angular,
Node.js) and uses free / open-source AI for speech-to-text, grammar checking and feedback.

## What students can practise

- **Speaking:** read aloud, listen & repeat, short answers, sentence builds, conversations, story
  retelling, and a 1–2 minute topic talk.
- **Written:** fill in the blanks, spot the error, sentence completion and other MCQs, dictation.
- **Mock tests:** timed, exam-like runs with a skill-wise score report (pronunciation, fluency,
  grammar, vocabulary, listening).
